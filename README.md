# Sistema de Ventas Macka

Sistema web desarrollado para gestionar las ventas de un emprendimiento de indumentaria.

## Funcionalidades

- Registro y organización de ventas.
- Gestión de pagos y saldos pendientes.
- Seguimiento de cuentas y movimientos.
- Visualización de totales y resúmenes.
- Organización de la información para facilitar el control del negocio.

## Tecnologías utilizadas

- HTML
- CSS
- JavaScript
- Firebase Hosting

## Acceso al sistema

El sistema se encuentra publicado y se puede acceder desde el siguiente enlace:

https://sistema-ventas-macka.web.app

## Sobre el proyecto

Proyecto personal desarrollado para aplicar conocimientos de desarrollo web y crear una herramienta que facilite la organización y administración de un emprendimiento real.
